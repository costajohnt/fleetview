# roost Implementation Plan

> **For agentic workers:** Implement this plan task-by-task, dispatching a fresh subagent per task where practical, with review between tasks. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** FleetView-style roster TUI (ink) that manages many backgrounded opencode sessions across multiple repos: dispatch, live status, enter (handoff to opencode's TUI), rename, kill.

**Architecture:** Single ink app + N detached `opencode serve` processes it owns via a registry file (`~/.config/roost/registry.json`). Sessions live server-side; roost is a thin client over `GET/POST /session`, `prompt_async`, `PATCH /session/:id`, and the SSE `/event` stream. "Enter" suspends ink and spawns `opencode attach <url> -s <id>` with inherited stdio.

**Tech Stack:** Node 26, ESM, ink + React, vitest + ink-testing-library. No SDK — thin `fetch` wrapper (the generated SDK adds nothing over 5 endpoints).

**Verified API facts (do not re-derive):**
- `opencode serve --port N --hostname 127.0.0.1` — headless server per repo.
- `opencode attach http://127.0.0.1:N -s <sessionId>` — attach TUI to a running server, open specific session.
- `GET /session` list · `POST /session` create (`{title?}`) · `DELETE /session/:id` · `PATCH /session/:id` rename (`{title}`) · `POST /session/:id/prompt_async` (body like message: `{parts: [{type:"text", text}]}`).
- SSE `GET /event`: first event `server.connected`, then bus events. `session.status` payload: `{sessionID, status: {type: "idle"|"busy"|"retry"}}`. `permission.updated` exists (pending permission → our `waiting`). Exact permission-clear event name is verified in the smoke task; the reducer also clears pending permissions on any `session.status` for that session as a fallback.

**File structure:**

```
roost/
├── package.json            ESM, bin: roost
├── src/
│   ├── cli.js              entry; roster↔attach handoff loop
│   ├── app.js              ink <App/>: wires store+mux+intents

│   ├── server-manager.js   detached spawn, health, kill, reap

│   └── ui/

import { readFileSync, writeFileSync, mkdirSync } from 'node:fs'
import { dirname, basename } from 'node:path'
import { createHash } from 'node:crypto'
import { homedir } from 'node:os'
import { join } from 'node:path'

export const defaultRegistryFile = () =>
  join(process.env.ROOST_CONFIG_DIR ?? join(homedir(), '.config', 'roost'), 'registry.json')

export function loadRegistry(file) {
  try {
    return JSON.parse(readFileSync(file, 'utf8'))
  } catch {
    return { repos: [] }
  }
}

function save(file, registry) {
  mkdirSync(dirname(file), { recursive: true })
  writeFileSync(file, JSON.stringify(registry, null, 2))
}

export function addRepo(file, path) {
  const registry = loadRegistry(file)
  const existing = registry.repos.find((r) => r.path === path)
  if (existing) return existing
  const used = new Set(registry.repos.map((r) => r.port))
  let port = 4801
  while (used.has(port)) port++
  const repo = {
    id: `${basename(path)}-${createHash('sha1').update(path).digest('hex').slice(0, 6)}`,
    path,
    name: basename(path),
    host: '127.0.0.1',
    port,
    pid: null,
    addedAt: new Date().toISOString(),
  }
  registry.repos.push(repo)
  save(file, registry)
  return repo
}

export function removeRepo(file, id) {
  const registry = loadRegistry(file)
  registry.repos = registry.repos.filter((r) => r.id !== id)
  save(file, registry)
}

export function updatePid(file, id, pid) {
  const registry = loadRegistry(file)
  const repo = registry.repos.find((r) => r.id === id)
  if (repo) repo.pid = pid
  save(file, registry)
}
```

export class OpencodeClient {
  constructor(baseUrl, fetchImpl = globalThis.fetch) {
    this.baseUrl = baseUrl.replace(/\/$/, '')
    this.fetch = fetchImpl
  }

  async #req(method, path, body) {
    const res = await this.fetch(`${this.baseUrl}${path}`, {
      method,
      headers: body ? { 'content-type': 'application/json' } : undefined,
      body: body ? JSON.stringify(body) : undefined,
    })
    if (!res.ok) throw new Error(`${method} ${path} → ${res.status}: ${await res.text()}`)
    return res.json()
  }

  listSessions() { return this.#req('GET', '/session') }
  createSession(title) { return this.#req('POST', '/session', { title }) }
  promptAsync(id, text) {
    return this.#req('POST', `/session/${id}/prompt_async`, { parts: [{ type: 'text', text }] })
  }
  renameSession(id, title) { return this.#req('PATCH', `/session/${id}`, { title }) }
  deleteSession(id) { return this.#req('DELETE', `/session/${id}`) }
}
```

import { spawn } from 'node:child_process'
import { openSync, mkdirSync } from 'node:fs'
import { homedir } from 'node:os'
import { join } from 'node:path'

const logDir = () => process.env.ROOST_LOG_DIR ?? join(homedir(), '.local', 'state', 'roost', 'logs')

export function spawnServer(repo, { spawnImpl = spawn, logFd } = {}) {
  if (logFd === undefined) {
    mkdirSync(logDir(), { recursive: true })
    logFd = openSync(join(logDir(), `${repo.id}.log`), 'a')
  }
  const child = spawnImpl('opencode', ['serve', '--port', String(repo.port), '--hostname', repo.host], {
    cwd: repo.path,
    detached: true,
    stdio: ['ignore', logFd, logFd],
  })
  child.unref()
  return child.pid
}

export async function isServerHealthy(repo, fetchImpl = globalThis.fetch) {
  try {
    const res = await fetchImpl(`http://${repo.host}:${repo.port}/session`, { signal: AbortSignal.timeout(2000) })
    return res.ok
  } catch {
    return false
  }
}

export function isPidAlive(pid) {
  if (!pid) return false
  try {
    process.kill(pid, 0)
    return true
  } catch {
    return false
  }
}

export function killServer(pid, killImpl = process.kill) {
  if (pid) killImpl(pid, 'SIGTERM')
}
```

### Task 5: session-store.js

Pure reducer. State: `{ sessions: { [key]: { repoId, id, title, status, hasRun, pendingPermissions: Set } }, offlineRepos: Set }`, key = `${repoId}:${sessionId}`.

Status derivation (single source of truth, in this order):
1. pendingPermissions non-empty → `waiting`
2. last `session.status` type `busy` or `retry` → `running`
3. type `idle` and `hasRun` → `done`
4. otherwise → `idle`

`hasRun` = session was `busy` at any point during this roost lifetime. `session.status` for a session clears its pendingPermissions (fallback so `waiting` can't stick).

`src/session-store.js`:
```js
export function createStore() {
  const sessions = new Map() // `${repoId}:${id}` → record
  const listeners = new Set()
  const key = (repoId, id) => `${repoId}:${id}`
  const notify = () => listeners.forEach((fn) => fn())

  const derive = (r) => {
    if (r.pendingPermissions.size > 0) return 'waiting'
    if (r.lastStatus === 'busy' || r.lastStatus === 'retry') return 'running'
    if (r.hasRun) return 'done'
    return 'idle'
  }

  const publicView = (r) => ({ repoId: r.repoId, id: r.id, title: r.title, status: derive(r) })

  return {
    setSessions(repoId, list) {
      for (const s of list) {
        const k = key(repoId, s.id)
        const prev = sessions.get(k)
        sessions.set(k, {
          repoId,
          id: s.id,
          title: s.title ?? s.id,
          lastStatus: prev?.lastStatus ?? 'idle',
          hasRun: prev?.hasRun ?? false,
          pendingPermissions: prev?.pendingPermissions ?? new Set(),
        })
      }
      notify()
    },

    apply(repoId, event) {
      const p = event.properties ?? {}
      if (event.type === 'session.status') {
        const r = sessions.get(key(repoId, p.sessionID))
        if (!r) return
        r.lastStatus = p.status?.type ?? 'idle'
        if (r.lastStatus === 'busy') r.hasRun = true
        r.pendingPermissions.clear() // fallback: status change supersedes stale permission
        notify()
      } else if (event.type === 'permission.updated') {
        const r = sessions.get(key(repoId, p.sessionID))
        if (!r) return
        r.pendingPermissions.add(p.id)
        notify()
      } else if (event.type === 'session.updated') {
        const r = sessions.get(key(repoId, p.info?.id))
        if (!r) return
        r.title = p.info.title ?? r.title
        notify()
      } else if (event.type === 'session.deleted') {
        if (sessions.delete(key(repoId, p.info?.id))) notify()
      }
      // all other bus events: ignore
    },

    get(repoId, id) {
      const r = sessions.get(key(repoId, id))
      return r ? publicView(r) : undefined
    },

    byRepo() {
      const groups = new Map()
      for (const r of sessions.values()) {
        if (!groups.has(r.repoId)) groups.set(r.repoId, [])
        groups.get(r.repoId).push(publicView(r))
      }
      return [...groups.entries()].map(([repoId, list]) => ({ repoId, sessions: list }))
    },

    subscribe(fn) {
      listeners.add(fn)
      return () => listeners.delete(fn)
    },
  }
}
```

export function parseSseChunk(buffer) {
  const events = []
  const blocks = buffer.split('\n\n')
  const rest = blocks.pop() // partial block stays buffered
  for (const block of blocks) {
    for (const line of block.split('\n')) {
      if (!line.startsWith('data:')) continue
      try {
        events.push(JSON.parse(line.slice(5).trim()))
      } catch {
        // malformed frame: skip
      }
    }
  }
  return { events, rest }
}

export function connectEvents(repo, { fetchImpl = globalThis.fetch, onEvent, onOffline, onOnline, reconnect = true }) {
  let stopped = false
  let delay = 1000

  const done = (async () => {
    while (!stopped) {
      try {
        const res = await fetchImpl(`http://${repo.host}:${repo.port}/event`)
        if (!res.ok || !res.body) throw new Error(`event stream ${res.status}`)
        onOnline?.(repo.id)
        delay = 1000
        let buf = ''
        for await (const chunk of res.body) {
          if (stopped) return
          buf += typeof chunk === 'string' ? chunk : new TextDecoder().decode(chunk)
          const { events, rest } = parseSseChunk(buf)
          buf = rest
          for (const e of events) onEvent(repo.id, e)
        }
        throw new Error('event stream ended')
      } catch {
        onOffline?.(repo.id)
        if (!reconnect || stopped) return
        await new Promise((r) => setTimeout(r, delay))
        delay = Math.min(delay * 2, 30_000)
      }
    }
  })()

  return { done, stop: () => { stopped = true } }
}

import React, { useState } from 'react'
import { Box, Text, useInput } from 'ink'

export function Launcher({ repos, onSubmit, onCancel }) {
  const [prompt, setPrompt] = useState('')
  const [stage, setStage] = useState('prompt') // 'prompt' | 'repo'
  const [repoIndex, setRepoIndex] = useState(0)

  useInput((input, key) => {
    if (key.escape) return onCancel()
    if (stage === 'prompt') {
      if (key.return) {
        if (prompt.trim()) setStage('repo')
      } else if (key.backspace || key.delete) {
        setPrompt((p) => p.slice(0, -1))
      } else if (input && !key.ctrl && !key.meta) {
        setPrompt((p) => p + input)
      }
    } else {
      if (key.upArrow) setRepoIndex((i) => Math.max(0, i - 1))
      else if (key.downArrow) setRepoIndex((i) => Math.min(repos.length - 1, i + 1))
      else if (key.return) onSubmit({ prompt: prompt.trim(), repoId: repos[repoIndex].id })
    }
  })

  return React.createElement(
    Box,
    { flexDirection: 'column' },
    React.createElement(Text, { bold: true }, 'New session'),
    React.createElement(Text, null, `> ${prompt}${stage === 'prompt' ? '█' : ''}`),
    stage === 'repo' &&
      React.createElement(
        Box,
        { flexDirection: 'column' },
        React.createElement(Text, { dimColor: true }, 'Repo:'),
        ...repos.map((r, i) =>
          React.createElement(Text, { key: r.id, color: i === repoIndex ? 'green' : undefined }, `${i === repoIndex ? '❯' : ' '} ${r.name}`),
        ),
      ),
  )
}

import React, { useEffect, useMemo, useState, useCallback } from 'react'
import { Box, Text, useInput, useApp } from 'ink'
import { createStore } from './session-store.js'
import { connectEvents } from './event-mux.js'
import { Roster, flattenGroups } from './ui/roster.js'
import { Launcher } from './ui/launcher.js'
import { Confirm } from './ui/confirm.js'

export function App({ repos, clientFactory, connectEventsImpl = connectEvents, ensureServerImpl, onAction }) {
  const { exit } = useApp()
  const store = useMemo(() => createStore(), [])
  const [, force] = useState(0)
  const [selected, setSelected] = useState(0)
  const [mode, setMode] = useState('roster') // roster | launcher | confirm-kill
  const [offlineRepos, setOfflineRepos] = useState(new Set())
  const rerender = useCallback(() => force((n) => n + 1), [])

  const clients = useMemo(
    () => new Map(repos.map((r) => [r.id, clientFactory(`http://${r.host}:${r.port}`)])),
    [repos, clientFactory],
  )

  useEffect(() => store.subscribe(rerender), [store, rerender])

  useEffect(() => {
    const conns = []
    for (const repo of repos) {
      ;(async () => {
        const up = await ensureServerImpl(repo)
        if (!up) return setOfflineRepos((s) => new Set(s).add(repo.id))
        store.setSessions(repo.id, await clients.get(repo.id).listSessions())
        conns.push(
          connectEventsImpl(repo, {
            onEvent: (repoId, e) => store.apply(repoId, e),
            onOffline: (repoId) => setOfflineRepos((s) => new Set(s).add(repoId)),
            onOnline: (repoId) =>
              setOfflineRepos((s) => {
                const next = new Set(s)
                next.delete(repoId)
                return next
              }),
          }),
        )
      })()
    }
    return () => conns.forEach((c) => c.stop())
  }, [repos])

  const groups = store
    .byRepo()
    .map((g) => ({ ...g, repoName: repos.find((r) => r.id === g.repoId)?.name ?? g.repoId }))
  const flat = flattenGroups(groups)
  const current = flat[Math.min(selected, Math.max(0, flat.length - 1))]
  const repoOf = (s) => repos.find((r) => r.id === s.repoId)

  useInput(
    (input, key) => {
      if (mode !== 'roster') return
      if (key.upArrow) setSelected((i) => Math.max(0, i - 1))
      else if (key.downArrow) setSelected((i) => Math.min(flat.length - 1, i + 1))
      else if (key.return && current) {
        const r = repoOf(current)
        onAction({ type: 'enter', url: `http://${r.host}:${r.port}`, sessionId: current.id })
        exit()
      } else if (input === 'n') setMode('launcher')
      else if (input === 'x' && current) setMode('confirm-kill')
      else if (input === 'q') {
        onAction({ type: 'quit' })
        exit()
      }
    },
    { isActive: mode === 'roster' },
  )

  if (mode === 'launcher') {
    return React.createElement(Launcher, {
      repos,
      onCancel: () => setMode('roster'),
      onSubmit: async ({ prompt, repoId }) => {
        setMode('roster')
        const client = clients.get(repoId)
        const session = await client.createSession(prompt)
        await client.promptAsync(session.id, prompt)
        store.setSessions(repoId, await client.listSessions())
      },
    })
  }

  if (mode === 'confirm-kill' && current) {
    return React.createElement(Confirm, {
      message: `Kill "${current.title}"?`,
      onResult: async (yes) => {
        setMode('roster')
        if (!yes) return
        await clients.get(current.repoId).deleteSession(current.id)
        store.apply(current.repoId, { type: 'session.deleted', properties: { info: { id: current.id } } })
      },
    })
  }

  return React.createElement(
    Box,
    { flexDirection: 'column' },
    React.createElement(Roster, { groups, selected, offlineRepos }),
    React.createElement(Text, { dimColor: true }, '↑↓ move · ⏎ enter · n new · x kill · q quit'),
  )
}

#!/usr/bin/env node
import React from 'react'
import { render } from 'ink'
import { spawnSync } from 'node:child_process'
import { App } from './app.js'
import { OpencodeClient } from './client.js'
import { loadRegistry, addRepo, updatePid, defaultRegistryFile } from './registry.js'
import { spawnServer, isServerHealthy } from './server-manager.js'

export function makeEnsureServer({ isServerHealthy, spawnServer, updatePid, registryFile, pollMs = 500 }) {
  return async function ensureServer(repo) {
    if (await isServerHealthy(repo)) return true
    const pid = spawnServer(repo, {})
    updatePid(registryFile, repo.id, pid)
    for (let i = 0; i < 10; i++) {
      await new Promise((r) => setTimeout(r, pollMs))
      if (await isServerHealthy(repo)) return true
    }
    return false
  }
}

async function main() {
  const registryFile = defaultRegistryFile()
  const ensureServer = makeEnsureServer({ isServerHealthy, spawnServer, updatePid, registryFile })

  // `roost add <path>` — register a repo without opening the UI
  const [cmd, arg] = process.argv.slice(2)
  if (cmd === 'add' && arg) {
    const repo = addRepo(registryFile, arg)
    console.log(`registered ${repo.name} → http://${repo.host}:${repo.port}`)
    return
  }

  for (;;) {
    const repos = loadRegistry(registryFile).repos
    if (repos.length === 0) {
      console.log('No repos registered. Run: roost add <path>')
      return
    }
    const action = await new Promise((resolve) => {
      const instance = render(
        React.createElement(App, {
          repos,
          clientFactory: (url) => new OpencodeClient(url),
          ensureServerImpl: ensureServer,
          onAction: (a) => {
            resolve(a)
            instance.unmount()
          },
        }),
      )
    })
    if (action.type === 'quit') break
    if (action.type === 'enter') {
      // hand the terminal to opencode's real TUI; return to roster on exit
      spawnSync('opencode', ['attach', action.url, '-s', action.sessionId], { stdio: 'inherit' })
    }
  }
}

// only run main when executed as a binary, not when imported by tests
if (import.meta.url === `file://${process.argv[1]}`) {
  main()
}
```

# roost

FleetView-style roster for [opencode](https://opencode.ai). Manage many
backgrounded opencode sessions across repos from one screen. Close roost,
sessions keep running; reopen and pick up where you left off.

## Install / run

    npm install
    node src/cli.js            # or: npm link && roost

    roost add ~/dev/myrepo     # register a repo (spawns a detached opencode serve on first open)
    roost                      # open the roster

## Keys

↑↓ move · ⏎ enter session (hands off to opencode's TUI; exit returns to roost)
n new session · r rename · x kill · q quit

## How it works

One detached `opencode serve` per registered repo (registry in
`~/.config/roost/registry.json`, logs in `~/.local/state/roost/logs/`).
roost is a thin client: REST for actions, SSE `/event` for live status
(running / waiting / done / idle). Entering a session runs
`opencode attach <url> -s <id>`.
```
